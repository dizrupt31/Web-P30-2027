# DiveCenter
Веб-приложение для управления дайвинг-центром. Разрабатывается в рамках учебной практики.
## Описание
Проект позволяет вести учёт клиентов, их сертификатов, бронирований погружений и оборудования. Реализован на ASP.NET Core с использованием Entity Framework Core.
## Технологии
- ASP.NET Core (Razor Pages)
- Entity Framework Core
- Git / GitHub
